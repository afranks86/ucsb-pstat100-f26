1

One sample, many possible estimates

We observe one sample, but a different sample would give a different estimate. The bootstrap uses our observed sample as a stand-in for the population to approximate this variability.

The recipe
  1. Draw n observations with replacement from the original sample of size n.
  2. Calculate the statistic you care about.
  3. Repeat B times. The SD of those B statistics estimates the statistic’s standard error.
ObjectWhat varies?
Data distributionIndividual observations in our sample
Sampling distributionA statistic across new samples from the population
Bootstrap distributionA statistic across resamples from our observed sample

Quick check

You have lengths of 50 hawks and calculate 2,000 bootstrap means. What are n and B? What does each entry of bootstrap_means represent?

Reveal answer & explanation

n = 50; B = 2,000. Each entry is the mean of one resample containing 50 draws from the original 50 hawks. It is neither an individual hawk length nor a mean of 2,000 hawks.

The histogram of these 2,000 means approximates how the sample mean varies. It is based on one observed sample, so it is an approximation to the unknown sampling distribution.

2

Work through a tiny bootstrap

Example + practice

Four observed waiting times, in minutes:

2   4   6   8

The sample mean is 5 minutes. The tiny sample makes the mechanics easy to see; it is not a recommendation to use only four observations for inference.

  1. Which are possible bootstrap samples of size 4?
    A. (2, 2, 8, 8)   B. (2, 4, 6, 8)
    C. (2, 4, 6)   D. (2, 4, 6, 10)
  2. Calculate the means of these three resamples: (2, 2, 4, 8), (4, 4, 6, 6), and (2, 6, 8, 8).
  3. What happens if you resample all four observations without replacement?
Reveal answer & explanation

1. A and B are valid. Repeats are allowed, but not required. C has the wrong size. D includes 10, which was never observed and cannot be drawn by this nonparametric bootstrap.

2. The means are 4, 5, and 6 minutes. For example, (2 + 2 + 4 + 8)/4 = 4. Each resample contributes exactly one number to the bootstrap distribution.

3. Without replacement, you only rearrange the same four observations. Every mean is 5, so the estimated SE is zero. This fails to capture uncertainty.

For the three illustrative means, R’s sample SD is √[((4 − 5)² + (5 − 5)² + (6 − 5)²)/(3 − 1)] = 1 minute. This shows the calculation, but B = 3 is far too small for a stable bootstrap SE.

3

Build—and debug—the R code

Practice

Complete the blanks to bootstrap the mean waiting time. Then identify what each of the three expressions below measures.

x <- c(2, 4, 6, 8)
set.seed(2026)
B <- 2000
bootstrap_means <- numeric(B)

for (b in seq_len(B)) {
  boot_sample <- sample(x, size = ___, replace = ___)
  bootstrap_means[b] <- ___(boot_sample)
}

mean(x)
sd(x)
sd(bootstrap_means)
Reveal answer & explanation

Use length(x), TRUE, and mean:

x <- c(2, 4, 6, 8)
set.seed(2026)
B <- 2000
bootstrap_means <- numeric(B)
for (b in seq_len(B)) {
  boot_sample <- sample(x, size = length(x), replace = TRUE)
  bootstrap_means[b] <- mean(boot_sample)
}
mean(x)                 # Point estimate: 5 minutes
sd(x)                   # Individual spread: about 2.582 minutes
sd(bootstrap_means)      # Bootstrap SE: typically near 1.118 minutes
sd(x) / sqrt(length(x))  # Formula-based SE: about 1.291 minutes

The point estimate stays mean(x). The bootstrap adds an estimate of its uncertainty. sd(x) describes individual waiting times, while sd(bootstrap_means) describes variability of the estimated mean.

Why are the two SE methods different here? For this empirical distribution, the variance of a single draw is 5, so the exact conditional bootstrap variance of the mean is 5/4. Its square root is about 1.118. The formula-based SE uses the sample variance with denominator n − 1. For the mean, the ideal bootstrap SE equals √((n − 1)/n) times that formula SE. The difference is noticeable at n = 4 and becomes small at larger n. Finite B adds simulation variability.

Find the bug

A classmate reports sd(bootstrap_means) / sqrt(B) as the standard error of the original sample mean. Is that correct?

Reveal answer & explanation

No. Use sd(bootstrap_means) directly. Each bootstrap mean already averages n observations, so its distribution already reflects the sample size.

Dividing by √B instead estimates the Monte Carlo standard error of the average of the B bootstrap means, conditional on the observed data. It does not estimate uncertainty in the original sample mean. Increasing B makes the bootstrap computation more stable; it does not create new observed data.

4

Change the statistic: bootstrap a median

Example + practice

Waiting times can be right-skewed. Suppose the target is the population median. Use these 12 illustrative observations:

wait <- c(1, 2, 2, 3, 3, 4, 4, 5, 6, 8, 12, 18)
  1. Find the sample median.
  2. Adapt the code from Section 3 to store 2,000 bootstrap medians.
  3. Write R code for the bootstrap SE and a 95% percentile confidence interval.
Reveal answer & explanation

The sample median is 4 minutes: the sorted sample has 12 values, so average positions 6 and 7, both equal to 4.

wait <- c(1, 2, 2, 3, 3, 4, 4, 5, 6, 8, 12, 18)
set.seed(2026)
B <- 2000
bootstrap_medians <- numeric(B)
for (b in seq_len(B)) {
  boot_sample <- sample(wait, size = length(wait), replace = TRUE)
  bootstrap_medians[b] <- median(boot_sample)
}
median(wait)
sd(bootstrap_medians)
quantile(bootstrap_medians, probs = c(0.025, 0.975))
hist(bootstrap_medians, main = "Bootstrap medians",
     xlab = "Median waiting time (minutes)")

The resampling step is unchanged. The statistic inside the loop changes from mean() to median(). Use the SD of the medians for their SE—not the median of the medians and not their SD divided by √B.

The percentile interval takes the 2.5th and 97.5th percentiles of the bootstrap statistics. Taking those percentiles of wait would instead summarize individual waiting times.

This small, tied dataset is for practice. Percentile intervals have approximate, not guaranteed, coverage; very small samples and some statistics can make the approximation poor.

Interpret uncertainty

Practice

In a separate study with a larger sample, suppose you obtain the following illustrative output for a population median. These numbers are provided for interpretation; they are not the output of Section 4.

QuantityResult (minutes)
Sample median4.0
Bootstrap SE0.8
2.5th percentile of bootstrap medians2.5
97.5th percentile of bootstrap medians6.0
  1. Report the estimate, SE, and 95% percentile interval.
  2. Which interpretation is correct?
    A. 95% of individual waiting times lie between 2.5 and 6.0.
    B. Across repeated studies, a well-calibrated 95% interval procedure would cover the true population median about 95% of the time.
    C. There is a 95% frequentist probability that the fixed population median lies inside this particular computed interval.
  3. Using the same bootstrap distribution, which quantiles give a 90% interval? Would it be wider or narrower?
  4. Does increasing B from 2,000 to 20,000 reduce the study’s SE by √10? What if n increases from 50 to 500 instead?
Reveal answer & explanation

1. Estimated population median: 4.0 minutes; estimated SE: 0.8 minutes; 95% percentile CI: [2.5, 6.0] minutes. This interval comes from quantiles, not automatically from estimate ± 1.96 × SE.

2. B is correct. Confidence describes the long-run performance of the procedure. A confuses a population parameter with individual observations. C assigns a frequentist probability to a fixed parameter in an already computed interval. The interval either contains the parameter or it does not; we do not know which.

3. Use quantile(bootstrap_medians, c(0.05, 0.95)). The 90% interval is narrower or equal in width because it leaves 5% in each tail rather than 2.5%. Ties can make widths equal.

4. Increasing B does not reduce the underlying study uncertainty. It reduces simulation noise in our estimate of that uncertainty. For an IID sample mean with unchanged population variance, increasing n from 50 to 500 reduces its theoretical SE by √10: the new SE is about 0.316 times the old one. The same exact formula is not universal for every statistic.

6

Optional extension: keep each hawk together

The lecture’s hawk example uses weights to account for unequal sampling. Here is a small illustrative dataset; samp_weight records the relative sampling propensity used in the lecture’s simplified estimator.

hawks <- data.frame(
  length = c(58, 60, 56, 50),
  samp_weight = c(9, 9, 9, 1)
)
ipw_mean <- function(lengths, samp_weights) {
  w <- 1 / samp_weights
  sum(w * lengths) / sum(w)
}

What is wrong with this resampling step? How would you fix it? Would simply bootstrapping the unweighted mean fix selection bias?

boot_lengths <- sample(hawks$length, replace = TRUE)
ipw_mean(boot_lengths, hawks$samp_weight)
Reveal answer & explanation

The lengths move, but their weights stay behind. A length can be paired with the wrong sampling weight. Resample row indices so each hawk keeps all its variables.

set.seed(2026)
B <- 2000
boot_ipw <- numeric(B)
for (b in seq_len(B)) {
  idx <- sample(seq_len(nrow(hawks)), nrow(hawks), replace = TRUE)
  boot_hawks <- hawks[idx, ]
  boot_ipw[b] <- ipw_mean(boot_hawks$length, boot_hawks$samp_weight)
}
ipw_mean(hawks$length, hawks$samp_weight) # 52 cm
sd(boot_ipw)

The unweighted mean is 56 cm; the weighted estimate is 52 cm. In this lecture-style bootstrap, rows are sampled uniformly. Reapplying the original sampling propensities during resampling would favor the overrepresented group again. The weights enter the statistic.

Bootstrapping the unweighted mean does not repair selection bias. The sample still overrepresents the same group. A narrow interval can be centered at a biased estimate. For actual complex surveys or substantial sampling without replacement, inference must account for the sampling design; this row bootstrap is a simplified illustration.

Exit check

Explain the bootstrap to a classmate in one sentence, using the words sample, replacement, statistic, and standard error.

Reveal answer & explanation

Repeatedly resample n observations with replacement from the observed sample, recompute the statistic, and use the SD of those statistics to estimate its standard error.

Before trusting the result, ask whether the sample represents the target population and whether the resampling unit matches how the data were collected. The ordinary bootstrap used here is designed for independent, identically distributed observations; dependence requires an appropriate resampling method.
